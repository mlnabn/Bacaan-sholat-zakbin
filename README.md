# Bacaan Sholat – Zakbin

Aplikasi mobile sederhana built with Flutter yang berisi:
- **Niat Sholat Wajib** (Subuh, Dzuhur, Ashar, Maghrib, Isya)
- **Bacaan lengkap Sholat** dalam Arab, Latin, dan artinya
- **Ayat Kursi** untuk bacaan tasyahud akhir

---

## 🚀 Fitur Utama

- Tampilan bacaan dalam format yang mudah dibaca
- Setiap bacaan dapat diperluas menggunakan ExpansionTile
- Teks dapat disalin (selectable text)
- Desain responsif untuk Android dan iOS

---
